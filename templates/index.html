PreMail

Preview your marketing emails before sending

Email Details

You can include inline styles and HTML formatting for accurate preview
Enter one URL per line. These images will be displayed below the email content.

How to Use

  1. Enter your email subject line
  2. Paste your HTML email content with inline styles
  3. Optionally add image URLs, one per line
  4. Click "Preview Email" to see the rendered result
  5. Test across different devices and email clients

Features

  • Preview on iPhone 17, Galaxy S25, iPad Pro, and more
  • Test in Gmail, Outlook, Apple Mail, and Yahoo Mail
  • See authentic email client UI with toolbars
  • Support for HTML with inline CSS
  • Preview opens in new tab for comparison

Best Practices

  • Use inline CSS for better email client compatibility
  • Always use absolute URLs for images
  • Test your email in multiple clients
  • Keep your design responsive

API Usage

POST /api/preview
Content-Type: application/json

{
  "subject": "Your Subject",
  "content": "<h1>Content</h1>",
  "images": ["url1", "url2"]
}
