📧 PreMail

Preview your marketing emails before sending

Email Details

Tip: You can include inline styles and HTML formatting
Enter one URL per line. These will be displayed below the email content.

ℹ️ How to Use

  1. Enter your email subject line
  2. Paste your HTML email content (with inline styles)
  3. Optionally add image URLs (one per line)
  4. Click "Preview Email" to see the rendered result

💡 Tips

  • Use inline CSS for better email client compatibility
  • Images in HTML should use absolute URLs
  • Test your preview in different screen sizes
  • Preview opens in a new tab for easy comparison

🔧 API Usage

POST /api/preview
Content-Type: application/json

{
  "subject": "Your Subject",
  "content": "<h1>Content</h1>",
  "images": ["url1", "url2"]
}
